Configure

Set each pedal's MIDI message, mode and LED colour from the browser. Changes apply straight away. Save them to keep them after unplugging.

Plug in your footswitch

Connect it over USB, then press Connect.

Works in Chrome, Edge and Firefox (not Safari). The browser asks to allow control of MIDI devices; that permission is needed to send settings to the pedal.

Device settings
Factory defaults Every pedal momentary and red, sending CC 102 and up on channel 1. Save afterwards to keep them.
Firmware update Reboots the Pico into its bootloader. Copy the new .uf2 file onto the RPI-RP2 drive that appears.

Prefer code? The same settings are available from the Rust, Python and JavaScript libraries and the fsctl command-line tool.
